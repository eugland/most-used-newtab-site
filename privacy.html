Privacy policy for New Tab: More Recent Visited

Last updated: September 2, 2026

New Tab: More Recent Visited works locally in your browser. It does not collect, transmit, sell, or share personal information or browsing data with the developer or third parties.

Data used by the extension

The extension uses Chrome's history permission to rank websites based on how frequently and recently they have been visited. It stores settings, pinned and hidden sites, blocklist entries, and a cached ranking in Chrome's local extension storage. If the user optionally enters a greeting name, that name is also stored only in local extension storage.

This information is processed and stored locally on the user's device. The extension has no developer-operated server, account system, advertising, analytics, or telemetry.

When a user intentionally submits a Google search, the browser navigates to Google with that query. This is normal website navigation initiated by the user; the query is not received by the extension developer.

The extension's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Permissions

  • History: Calculates the most frequently and recently visited sites.
  • Favicons: Displays locally available icons for those sites.
  • Storage: Saves settings and a cached site ranking locally.
  • Context menus: Provides a shortcut to extension settings.

Retention and deletion

Locally stored extension data remains in Chrome until the user changes or clears it, clears extension storage, or uninstalls the extension. Because no data is sent to the developer, the developer has no remote copy to retain or delete.

Changes

This policy may be updated if the extension's behavior changes. The latest version will remain available on this page.
